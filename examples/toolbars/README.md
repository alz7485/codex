# ツールバーのサンプル

同じ名前のJSONとMACを用意しています。JSONをFormDesignerで開くと継続編集できます。

| ファイル | 用途 |
| --- | --- |
| `dialog-navigation` | 通常DIALOG内の操作ボタン列。CE情報・直属の上位への移動・配下一覧。 |
| `main-navigation` | MAIN用の標準TOOLBAR。同じ3ボタンを宣言順に配置。 |
| `dialog-custom-macro` | カスタム処理のメソッドと、外部MACを呼び出すボタン。 |

`CE info` は現在要素の名前・種類、`Up` は直属のOWNERへの移動、`Members` は直属の配下の名前・種類をコマンド出力へ表示します。
`Members` は現在要素を移動しません。現在要素がない場合、または上位・配下がない場合は案内します。

外部マクロの `C:/E3D/macros/example.mac` はサンプルのパスです。
実際に配置したマクロのパスへ変更してください。マクロ本体は同梱していません。
`Run` のサンプル本文はメッセージを表示するだけです。自分の処理へ置き換えてください。

標準TOOLBARはメニューバーを持つモジュール用で、リボンへの登録は含みません。
MAINの実際の表示・登録方法は利用するアプリケーションに合わせてください。MACには既存仕様どおりSHOWも含まれます。
E3D 4.0実機での実行は未検証です。[作成ガイド](../../docs/toolbar-builder.md)も参照してください。
