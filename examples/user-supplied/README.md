# ユーザー提示MAC（写真からの転記）

`HsMacMSR.mac` はチャットに提示されたコード写真から転記した参考原稿です。元のMACファイルのバイト列は提供されていないため、元ファイルとの完全一致は保証できません。名前、値、外部マクロ呼び出しはデモ用に置き換えていません。フォーム名 `!!HsMacMSR` はユーザー確認済みです。

- 保存形式：SJIS（CP932）、CRLF、拡張子 `.mac`。
- `$$DIALOG DOCK RIGHT` と、DEFAULT内の `OPTIONxA0001`（宣言名 `_OPTIONxA0001` と異なる表記）も転記原稿に保持しています。アプリの再出力による修正はしていません。読み取りが曖昧な記号は元のコードで確認してください。
- `%PDMSUSER%/SUB/MSRsub1.mac` ～ `MSRsub4.mac` は元の呼び出し先です。これら外部ファイルの内容は提示されておらず、同梱していません。
- 転記ファイルと外部マクロは実行していません。

`../measure-layout.mac` はGUI確認用の別サンプルで、処理をデモ用に置き換えています。この転記原稿とは別のファイルです。
