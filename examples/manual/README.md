# 詳細マニュアル第4章の完成サンプル

「設備名を入力し、実行ボタンでその文字を表示するフォーム」です。
[詳細マニュアルの作成手順](../../MANUAL.md#first-form) と同じ本文を使っています。

1. FormDesignerの「開く」で [first-form.json](first-form.json) を選びます。
2. 「設備名」の初期値 `P-101`、入力部品 `equipmentName`、実行ボタンを確認します。
3. 実行ボタンの「動作」から処理コードを開き、入力値の取得・空欄の判定・メッセージ表示を確認します。
4. JSONを別名で保存し、必要に応じてMACを出力します。

[first-form.mac](first-form.mac) はCP932（Windowsの日本語SJIS）・CRLFです。
UTF-8として開くと日本語が崩れるので、エディターの文字コードを指定してください。
FormDesignerへMACを読み込んでも、入力部品・初期値・メソッドを編集できます。

処理を実行する場所はE3Dです。FormDesignerの参考表示は静的な表示です。
E3D 4.0実機での構文・実行は未検証です。
