E3D PML Form Designer — Windows EXE化手順（onedir）

Windows上でビルドしてください。Python 3.12（64bit）を使用します。
ZIPを展開し、このテキストと run_designer.py があるフォルダーを
PowerShellで開いて、以下を上から順に実行してください。

自動ビルドする場合は、以下の1行で依存関係の導入・アイコン付きEXEの作成・
サンプルと説明書のコピーを実行できます。

powershell -NoProfile -ExecutionPolicy Bypass -File .\build_onedir.ps1

app-icon.ico と app-icon.png は、この手順書と同じフォルダーにも同梱しています。
以前のコマンドやspecファイルで作成したEXEには自動反映されません。
上のスクリプトまたは以下のアイコン付きコマンドで再ビルドしてください。

1. ビルド用仮想環境の作成と依存パッケージのインストール

py -3.12 -m venv .venv-build
.\.venv-build\Scripts\python.exe -m pip install --upgrade pip
.\.venv-build\Scripts\python.exe -m pip install -r requirements.txt
.\.venv-build\Scripts\python.exe -m pip install "pyinstaller>=6.16,<7"

2. onedir形式でEXEを作成

.\.venv-build\Scripts\python.exe -m PyInstaller --onedir --windowed --clean --noconfirm --name E3DFormDesigner --icon .\e3d_designer\assets\app-icon.ico --add-data "e3d_designer\assets;e3d_designer\assets" run_designer.py

3. サンプル・使い方・この手順書を配布フォルダーにコピー

Copy-Item -Path .\examples -Destination .\dist\E3DFormDesigner\examples -Recurse -Force
Copy-Item -Path .\EXE_BUILD_ONEDIR.txt -Destination .\dist\E3DFormDesigner\EXE_BUILD_ONEDIR.txt -Force
Copy-Item -Path .\app-icon.ico -Destination .\dist\E3DFormDesigner\app-icon.ico -Force
Copy-Item -Path .\app-icon.png -Destination .\dist\E3DFormDesigner\app-icon.png -Force

New-Item -ItemType Directory -Path .\dist\E3DFormDesigner\e3d_designer -Force | Out-Null
Copy-Item -Path .\e3d_designer\assets -Destination .\dist\E3DFormDesigner\e3d_designer\assets -Recurse -Force
Copy-Item -Path .\USER_GUIDE.txt -Destination .\dist\E3DFormDesigner\USER_GUIDE.txt -Force
Copy-Item -Path .\README.md -Destination .\dist\E3DFormDesigner\README.md -Force
Copy-Item -Path .\docs -Destination .\dist\E3DFormDesigner\docs -Recurse -Force

4. 起動

.\dist\E3DFormDesigner\E3DFormDesigner.exe

出力先と配布方法

dist\E3DFormDesigner\
  E3DFormDesigner.exe
  app-icon.ico / app-icon.png
  _internal\              Python・PySide6・Qtなどの実行用ファイル
  examples\               JSON設計ファイルとPMLサンプル
  EXE_BUILD_ONEDIR.txt
  e3d_designer\assets\     アイコンPNG・ICO
  USER_GUIDE.txt            基本操作とショートカット
  README.md / docs\        詳細説明と画面例

dist\E3DFormDesigner フォルダー全体をZIPにして配布してください。
EXEだけをコピーすると起動できません。配布先でPythonを別途
インストールする必要はありません。

起動後、「開く」で examples\gadgets.json を選ぶと追加部品を試せます。
examples\extra-features.json は画像・複数行入力・DBセレクタ・
ポップアップのサンプル、examples\toolbar.json はMAINのツールバー例です。
サンプル画像は examples\assets に含まれます。相対パスの画像は
設計JSONのフォルダー、次にEXEのフォルダーから探します。
E3Dへは画像ファイルも別途配置します。
設計の保存先とPMLの出力先は、書き込み可能な場所を選んでください。

起動に失敗する場合（コンソールでエラーを確認）

.\.venv-build\Scripts\python.exe -m PyInstaller --onedir --console --clean --noconfirm --name E3DFormDesignerDebug --icon .\e3d_designer\assets\app-icon.ico --add-data "e3d_designer\assets;e3d_designer\assets" run_designer.py
.\dist\E3DFormDesignerDebug\E3DFormDesignerDebug.exe

補足

・仮想環境の有効化（Activate.ps1）は不要です。
・run_designer.py はEXE化用の起動ファイルです。パッケージ内の
  e3d_designer\__main__.py を直接ビルドする代わりに使用します。
・この手順はWindows向けです。Windows EXEのビルド・起動確認は
  クラウド環境では未実施です。
・E3D本体や、CONTAINERで使う外部DLLはこのEXEには含まれません。
