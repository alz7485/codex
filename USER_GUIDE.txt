E3D PML Form Designer — はじめに

1. 起動・サンプル
   EXE版は E3DFormDesigner.exe を開きます。
   「開く」で examples/equipmenttool.json を選ぶと基本的なフォーム、
   examples/tabdemo.json でタブ、examples/extra-features.json で画像等を試せます。
   Python版の起動・EXE化は EXE_BUILD_ONEDIR.txt を参照してください。

作業の流れ
   キャンバスを常時表示し、部品の追加・配置・設定を同じ画面で行います。
   「コードを表示」（Ctrl+Shift+C）で生成コードと保存・出力を別ウィンドウに表示します。
   コードを開閉しても部品ボタンやキャンバスの配置は変わりません。
   フォーム名・部品名・処理名は設定済みで、名前の手入力は必要ありません。
   名前を分かりやすく管理したい場合だけ編集します。
   必要な変数は自動作成し、追加のグローバル変数の入力は任意です。

2. 部品を配置
   キャンバス上部のボタンで追加し、ドラッグで移動します。矢印から種類を
   選び、本体を押すと選択した種類を繰り返し追加できます。右端・下端・右下の
   ハンドルでサイズを変更します。表示文字はダブルクリックで変更できます。
   移動・サイズ変更は左ボタンで操作し、操作中のEscで取り消せます。
   キャンバスの矢印キーで0.5、Alt＋矢印キーで0.1単位移動します。
   CtrlまたはShiftを押してクリックすると、複数選択を追加・解除できます。
   FRAMEをキャンバスまたはツリーで右クリックして「子を含めてすべて選択」を
   選ぶと、FRAME自身と入れ子の子部品をまとめて選択できます。
   複数選択中は右側が灰色になり、個別の設定は編集できません。
   選択した部品をキーやドラッグでまとめて移動し、Deleteでまとめて削除できます。
   親と子を選択しても、子の内部座標は保持します。Undoで1操作ずつ戻せます。
   コードで使う名前は右の部品名欄、または「編集 → 変数・名前管理」で変更します。
   フレーム内はフレーム左上を基準に座標を設定します。
   左の追加先表示を確認してください。空きがない場合はサイズを広げます。

3. 設定を編集
   右側の「プロパティ」で基本・配置・内容・動作を切り替えます。
   初期値欄の内容は DEFAULT メソッドに自動出力されます。
   DEFAULTやリスト初期化メソッドを、呼び出すコンストラクタより先に定義します。
   実行時は選択肢・表データを設定してからDEFAULTで初期値を設定します。
   TEXT・文字PARAGRAPH・チェック・プルダウン・コンボは高さ1行固定です。
   高さ欄は読み取り専用で、縦と右下のサイズ変更ハンドルは表示しません。
   画像チェック・画像OPTIONは元画像のサイズに固定します。
   画像OPTIONの一部の画像が読めない間は、保存済みサイズを縮めません。
   全画像の復帰時や読めない項目の削除時は、残った元画像サイズへ更新します。
   通常チェック・文字プルダウンの「幅（プレビューのみ）」はMACへ反映しません。
   コンボのSCROLLは、プルダウンを開いたときの表示量です。
   線は横の高さ／縦の幅が1.0固定です。
   スライダーは横の高さが1.0、縦の幅が3.0固定です。
   右パネルとダブルクリックのミニ編集で、線・スライダーの向きを変更できます。
   向き変更は幅・高さを入れ替えた後、太さを固定値に戻します。長さは保持します。
   チェック・ラジオの初期値は空欄/TRUE/FALSEから選びます。
   テキスト入力のプレビューは表示名と入力枠を分け、枠内に初期値を表示します。
   フォーム枠を選択するとタイトル・サイズ・表示形式・変数を指定できます。
   「処理」で DEFAULT の追加処理や表示後のコードを入力します。
   メニューバーは上部の「メニューバー」から別ウィンドウで編集します。
   追加したメニューバーのプレビューのダブルクリックでも開けます。
   操作部品には処理メソッド名を自動設定します。初期内容はコメントだけです。
   必要な処理だけ「処理コードを編集」から追加してください。CALLを入力すると
   メソッド指定を解除します。元に戻す操作で戻せます。

4. タブを作成
   上部の「フレーム」の矢印から「タブ」を選ぶとTABSETと2つのタブを作成します。
   さらに追加するときはプレビュー上部の「＋ タブ」を使います。
   TABSETを選択して通常の「フレーム」を追加すると、現在のタブ内に
   移動できるFRAMEを作成します。ツリーからTABSETへドロップする場合も
   現在のタブ内へ配置します。タブのないTABSETには先に「＋ タブ」で追加します。
   見出しを選ぶと表示と追加先が切り替わります。
   見出しをドラッグするとTABSET全体を移動します。タブ1・2のFRAMEと
   部品はドラッグ中から追従し、非表示のページも同じ位置へ移動します。
   子の内部座標は保持し、Escで取り消し、確定後はUndoで戻せます。
   TABSETを選択すると幅・高さ・右下のハンドルでサイズを変えられます。
   タブFRAMEが重なっていてもハンドルを操作できます。フォーム全体を
   選んだ場合も、全面のFRAMEよりフォームのハンドルを優先します。
   キャンバスのタブ見出しをダブルクリックするとそのタブの表示名を変更できます。
   コード用の名前は「タブ設定」で変更します。

5. 保存とMAC出力
   「コードを表示」の別ウィンドウで保存状態・入力チェック・生成コードを確認できます。
   「保存」は編集用JSONを保存します。「ファイル → 名前を付けて保存」は別名で保存し、
   以降はそのファイルを編集します。サンプルを使う場合は別名保存が便利です。
   「MAC 出力」はSJIS（CP932）・CRLFのテキストを.macで保存します。
   JSONは再編集用、MACはE3Dへ渡す実行用です。MACの読み込み機能はありません。
   出力先フォルダを変更すると、アプリと同じ場所のsettings.jsonに記録します。
   画面下のステータスに保存・出力したパスを表示します。
   コード欄に「出力できません」とある場合は、表示された入力エラーを修正します。

6. 最近の設計・作業の復元
   「最近の設計」から最近のJSONを10件まで選べます。
   未保存作業を30秒ごとにアプリ横のrecoveryフォルダへ保存します。
   次の起動時の案内、または「ファイル → 作業を復元」から残った作業を復元できます。
   復元後は内容を確認して保存してください。Undo履歴は復元しません。
   通常の保存・明示的な破棄で、その作業のバックアップを削除します。
   バックアップできない入力エラーはステータスに表示し、前の成功分を保持します。
   バックアップ前の直近30秒以内の変更や、書き込みできない場所での変更は
   保護できません。元のJSONを定期的に保存してください。

7. 画像
   画像選択ボタンでファイルを選ぶか、画像パスを指定します。
   元ファイルの幅・高さ（ピクセル）を取り込み、部品サイズを固定します。
   幅・高さの入力欄は読み取り専用で、サイズ変更ハンドルは表示しません。
   画像選択は選択肢の最大幅・最大高さに固定し、画像自体は拡大縮小しません。
   元画像が収まらない場合はフォーム／フレームを広げるか元画像を編集します。
   読めないサーバー画像は設計に保存された寸法を保持します。
   TEXT（1行入力）の高さも1行に固定します。横幅は変更できます。
   相対パスは設計JSONのフォルダ、次にアプリのフォルダから探します。
   プレビューのための検索は保存・出力するパスを書き換えません。
   別フォルダへJSONを保存する場合は、画像も配置するか絶対パスで指定します。
   E3D側にも画像を配置し、E3Dから参照できるパスにしてください。
   \\SERVER\Images$\sample.png のようなサーバー共有パスも使用できます。
   画像と画像選択のパスは共有名の$を保持して保存・出力します。
   プレビューは、実行中のPCから共有ファイルへアクセスできる場合に表示します。

よく使うキー
   Ctrl+N          新規
   Ctrl+O          開く
   Ctrl+S          保存
   Ctrl+Shift+S    名前を付けて保存
   Ctrl+E          MAC出力
   Ctrl+Z          元に戻す
   Ctrl+Shift+Z    やり直す
   Ctrl+D          複製
   Ctrl+C / X / V  コピー / 切り取り / 貼り付け
   Delete          部品を削除
   矢印キー         選択した部品を0.5単位で移動（キャンバス）
   Alt＋矢印キー     選択した部品を0.1単位で移動（キャンバス）
   Ctrl+M          変数・名前管理
   文字入力欄ではコピー・貼り付け・Deleteは文字を編集します。

配布
   EXE版は_internalやexamplesを含むE3DFormDesignerフォルダ全体を配布します。
   app-icon.icoとapp-icon.pngを同梱し、ウィンドウとEXEにアイコンを設定しています。
   E3D本体・外部DLLは同梱しません。

確認状況
   プレビューは概略表示です。E3D 4.0実機での構文・表示・動作と
   Windows EXEのビルド・起動は未検証です。BACKGROUNDの色見本は近似色です。
   詳細な構文と機能はREADME.mdを参照してください。


ダブルクリックのミニ編集画面
・キャンバスまたは部品リストをダブルクリックすると、その部品用の編集画面が開きます。
・オブジェクト名、表示名、初期値、処理、色、WIDTH、HEIGHTのうち対応する項目を表示します。
・OPTIONとCOMBO／COMBOBOXの「項目・値を表で編集…」で表示名とコマンド／実値を編集します。
・LISTは表示名／実値の形式か表形式を選べます。表形式では先頭行が見出しです。＋行・－行・＋列・－列で編集し、初期選択は1からの行番号を指定します。
・内側の表を確定しても、外側をキャンセルすれば変更を破棄します。外側のOKでまとめて反映し、Undoで戻せます。
・オブジェクト名の変更はコードの参照にも反映します。E3D実機での動作は別途確認してください。

マクロフォルダの指定
・ボタンの処理方式を「外部マクロを実行」にすると、動作ページにマクロフォルダ欄が表示されます。
・フォルダを入力、または隣のフォルダボタンで選択すると settings.json に保存します。初期値はアプリと同じフォルダです。
・「マクロファイルを選択」はこのフォルダから開きます。出力先フォルダとは別の設定で、すべてのボタンで共有します。

空のメソッドの出力
・処理本文が空欄、空白だけ、コメントだけの場合はメソッド定義と対応するCALL／コールバックを出力しません。
・コメントは --、$* の行コメントと、$( から $) までのブロックコメントに対応します。
・メソッドの定義順の解析でもコメント内の呼び出しを除外します。本文の表記は保持します。
・画面の自動メソッド名は保持します。処理本文を入力すると呼び出しと定義を自動出力します。
・初期値を設定した部品のDEFAULTや、外部マクロ用の生成メソッドは必要な処理があるため出力します。

ユーザー入力の大文字小文字
・名前、表示名、値、コマンド、パスは入力の表記を保持して出力します。
・メソッド本文、DEFAULT本文、表示後のプログラム、ビューの処理も大小文字を変換しません。自動生成するPMLキーワードだけ表記を整えます。
・名前管理のPML名、MAC出力の標準ファイル名、マクロの分岐値も入力の表記を保持します。

フォーム枠の編集
・フォーム全体をキャンバスの枠として表示します。見出し、枠、部品のない場所をクリックするとフォームを選択できます。
・右側の「プロパティ」はフォーム設定と部品設定を選択に応じて切り替えます。専用のフォームタブはありません。
・フォーム枠の右・下・右下のハンドルで横幅・縦幅を変更できます。部品の位置とサイズは変わりません。部品がはみ出す縮小はできません。Undo・Redoに対応します。
・見出しをダブルクリックするとフォーム名・表示名・WIDTH・HEIGHT・表示形式のミニ設定画面が開きます。
・通常ダイアログのサイズはPMLに出力します。ドッキング／MAINの実表示サイズはE3D側のレイアウトにも依存します。

COMBOのイベント処理
・コールバックはコンストラクタ内で設定し、メソッドに !gad（部品）と !event（イベント名）を渡します。選択時だけ処理する場合は if !event.eq('SELECT') then で分岐できます。
・ボタン等の引数なしメソッドとは別のメソッド名を使います。処理が空の場合は設定・定義を出力しません。

COMBOのSCROLL
・COMBO／COMBOBOXの「内容」プロパティ、またはダブルクリックのミニ編集でSCROLL（表示量）を設定できます。初期値は20です。
・正の整数を入力すると、宣言のWIDTHの前に SCROLL 値 を出力します。空欄ならSCROLLを省略します。

COMBOのTAGWID
・COMBO／COMBOBOXの「内容」プロパティとミニ編集でTAGWID（表示名の幅）を設定できます。
・表示名の直前に TAGWID 値 を出力します。0以上の数値を指定でき、空欄なら省略します。
・例: COMBO .Choice TAGWID 6 '選択' AT X 2 Y 1 SCROLL 20 WIDTH 18

ツリーエクスプローラ
・examples/tree-explorer.jsonを開くと、入れ子のフレームとタブの階層を試せます。
・左側全体をフォーム → フレーム → 部品のツリーにしました。TABSET → タブのフレーム → 部品も同じツリーに表示します。
・矢印でフォルダを開閉します。別タブの部品を選ぶと、そのタブへ切り替わります。ダブルクリックでミニ設定画面を開きます。
・フォームを選べばフォーム直下、フレームを選べばその中に追加します。追加ボタンはキャンバス列の上部に14個にまとめて表示し、幅に合わせて折り返します。関連する部品は矢印のメニューで選択できます。ツリーとプロパティは上端から表示します。追加したメニューバーのプレビューを枠で囲みます。
・ドラッグで並び替え、フレームへのドロップで所属を変更できます。新しい親の領域内へ座標を取り直します。自分・子孫への移動や収まらない移動は拒否します。タブのフレームは同じTABSET内で並び替えます。
・フォルダの開閉は設計に影響しません。並び替えと所属変更はUndo／Redo・保存に対応します。
・Ctrlで複数選択、Shiftで範囲選択できます。キャンバスの選択にも同期します。
・選択を追加・解除しても非表示タブの選択は保持します。名前管理でリネーム
  しても複数選択と表示中のタブを維持します。新規・読み込み・作業の復元では
  前の選択とタブの表示状態をリセットします。
・FRAMEの右クリックから「子を含めてすべて選択」でFRAMEと子孫を選択できます。
  TABSETは非表示のタブも含め、各タブのFRAMEはそのページ内だけを選びます。
・相対配置、AUTO配置、ツールバー内の部品、タブページFRAME自身の座標は固定です。
  コピー・複製・ツリーでの所属変更は1個を選択して行います。

追加ボタンの並び（通常幅）
   1行目：ボタン、プルダウン、フレーム、チェック、横線、メニューバー、コンテナ
   2行目：入力、ラベル、リスト、スライダー、コマンド、DBセレクタ、ツールバー
   狭い幅では順序を保って折り返します。
