E3D PML Form Designer — はじめに

1. 起動・サンプル
   EXE版は E3DFormDesigner.exe を開きます。
   「開く」で examples/equipmenttool.json を選ぶと基本的なフォーム、
   examples/tabdemo.json でタブ、examples/extra-features.json で画像等を試せます。
   Python版の起動・EXE化は EXE_BUILD_ONEDIR.txt を参照してください。

作業の流れ
   上部の①フォーム設定 → ②部品を配置 → ③動作を設定 → ④確認・出力で
   必要な画面へ移動します。どこからでも切り替えられます。
   配置画面はキャンバスを広く、出力画面はコードと保存・出力を広く表示します。
   フォーム名・部品名・処理名は設定済みで、名前の手入力は必要ありません。
   名前を分かりやすく管理したい場合だけ編集します。
   必要な変数は自動作成し、追加のグローバル変数の入力は任意です。

2. 部品を配置
   左のボタンで追加し、ドラッグで移動します。右端・下端・右下の
   ハンドルでサイズを変更します。表示文字はダブルクリックで変更できます。
   コードで使う名前は右の部品名欄、または「編集 → 変数・名前管理」で変更します。
   フレーム内はフレーム左上を基準に座標を設定します。
   左の追加先表示を確認してください。空きがない場合はサイズを広げます。

3. 設定を編集
   右側の「部品」で基本・配置・内容・動作を切り替えます。
   初期値欄の内容は DEFAULT メソッドに自動出力されます。
   「フォーム」でタイトル・サイズ・表示形式・変数を指定します。
   「処理」で DEFAULT の追加処理や表示後のコードを入力します。
   メニューバーは左の「メニューバー」から別ウィンドウで編集します。
   操作部品には処理メソッド名を自動設定します。初期内容はコメントだけです。
   必要な処理だけ「処理コードを編集」から追加してください。CALLを入力すると
   メソッド指定を解除します。元に戻す操作で戻せます。

4. タブを作成
   左の「タブ」でTABSETと2つのタブをまとめて作成できます。
   さらに追加するときはプレビュー上部の「＋ タブ」を使います。
   見出しを選ぶと表示と追加先が切り替わります。
   キャンバスのタブ見出しをダブルクリックするとそのタブの表示名を変更できます。
   コード用の名前は「タブ設定」で変更します。

5. 保存とMAC出力
   「④ 確認・出力」で保存状態・入力チェック・生成コードを確認できます。
   「保存」は編集用JSONを保存します。「ファイル → 名前を付けて保存」は別名で保存し、
   以降はそのファイルを編集します。サンプルを使う場合は別名保存が便利です。
   「MAC 出力」はSJIS（CP932）・CRLFのテキストを.macで保存します。
   JSONは再編集用、MACはE3Dへ渡す実行用です。MACの読み込み機能はありません。
   出力先フォルダを変更すると、アプリと同じ場所のsettings.jsonに記録します。
   画面下のステータスに保存・出力したパスを表示します。
   コード欄に「出力できません」とある場合は、表示された入力エラーを修正します。

6. 最近の設計・作業の復元
   「最近の設計」から最近のJSONを10件まで選べます。
   未保存作業を30秒ごとにアプリ横のrecoveryフォルダへ保存します。
   次の起動時の案内、または「ファイル → 作業を復元」から残った作業を復元できます。
   復元後は内容を確認して保存してください。Undo履歴は復元しません。
   通常の保存・明示的な破棄で、その作業のバックアップを削除します。
   バックアップできない入力エラーはステータスに表示し、前の成功分を保持します。
   バックアップ前の直近30秒以内の変更や、書き込みできない場所での変更は
   保護できません。元のJSONを定期的に保存してください。

7. 画像
   画像選択ボタンでファイルを選ぶか、画像パスを指定します。
   相対パスは設計JSONのフォルダ、次にアプリのフォルダから探します。
   プレビューのための検索は保存・出力するパスを書き換えません。
   別フォルダへJSONを保存する場合は、画像も配置するか絶対パスで指定します。
   E3D側にも画像を配置し、E3Dから参照できるパスにしてください。

よく使うキー
   Ctrl+N          新規
   Ctrl+O          開く
   Ctrl+S          保存
   Ctrl+Shift+S    名前を付けて保存
   Ctrl+E          MAC出力
   Ctrl+Z          元に戻す
   Ctrl+Shift+Z    やり直す
   Ctrl+D          複製
   Ctrl+C / X / V  コピー / 切り取り / 貼り付け
   Delete          部品を削除
   Ctrl+M          変数・名前管理
   文字入力欄ではコピー・貼り付け・Deleteは文字を編集します。

配布
   EXE版は_internalやexamplesを含むE3DFormDesignerフォルダ全体を配布します。
   app-icon.icoとapp-icon.pngを同梱し、ウィンドウとEXEにアイコンを設定しています。
   E3D本体・外部DLLは同梱しません。

確認状況
   プレビューは概略表示です。E3D 4.0実機での構文・表示・動作と
   Windows EXEのビルド・起動は未検証です。BACKGROUNDの色見本は近似色です。
   詳細な構文と機能はREADME.mdを参照してください。
