# 既存タブから複製する操作（2026-10-08）

![タブ複製の操作行](tab-duplicate-controls.png)

「設備」タブを「📋 タブ複製」でコピーすると、「設備 (コピー)」が追加されて表示されます。中の部品・配置・関連処理もコピーし、新しいオブジェクト名を自動設定します。「＋ タブ」は空のページ追加です。実際のQt描画です。

# コード・プレビューボタンを追加した操作行（2026-10-08）

![拡大縮小と同じ行のコード・プレビューボタン](code-preview-controls.png)

「📝 コード」は生成コード、「🖥️ プレビュー」は実機仕様の参考表示を別ウィンドウで開きます。表示中なら手前へ戻し、最小化からも復帰します。実際のQt描画です。画像は150%表示ですが、初期倍率は100%のままです。
