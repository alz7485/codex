# .NET部品の簡単作成の検証（2026-10-11）

## 変更

- 「その他」と「編集」に.NET部品の作成画面を追加。既存パレットは16個・8列×2行。
- 表、ファイル選択、My Data登録、Flexible Explorerラッパー接続、サポート寸法部品接続、自作部品接続の6種類。
- 表は手入力または現在要素の直属のMEMBERSのName／Typeを読み取り専用で表示するコードを生成。
- CONTAINERに初期化コードを保存し、名前変更・複製・別設計へのコピー時に参照を書き換える。
- CONTAINERの生成コードではコンストラクタ内にも名前空間を指定。
- IMPORT既読込の公式ハンドラーを生成し、構造を限定してMAC読込にも対応。
- 配置・コード追加はトランザクションとして行い、1回のUndoで取り消す。
- 初期化が無視される元コード保持モード、不正な名前、名前衝突、空きのない配置への追加を拒否。

## 確認結果

- 全86テストファイルを個別プロセスで実行し、合計1017件成功（134.4秒）。単一プロセスの全体実行はメモリ上限で終了したため、個別実行へ変更。
- 新規17件ではPMLの接続順、JSON保存、名前変更、同一／別設計への複製、MAC再読込、複数アセンブリ、OPEN／SAVE、キャンセル用コード、入力検証、失敗時の履歴保持、フレーム／タブ配置を確認。
- 実際のメニューから作成ダイアログを開き、追加・初期化編集・Undoを確認。
- 5種類の同梱JSONとMACが一致し、MAC読込後のJSON保存・再出力が可能であることを確認。
- Qt offscreenで作成画面と配置画面を確認し、画像をdocs/current-uiへ保存。
- git diff --check成功。

## 実行範囲

確認したのはFormDesigner内のUI、モデル、PMLコードの生成・保持です。
