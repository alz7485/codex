# ツールバーを簡単作成

ツールバーは、よく使う処理を横一列のボタンに並べて、すぐ呼び出せるようにするものです。
FormDesignerでは、作成手順の案内を見ながら、ボタンとPMLメソッドをまとめて追加できます。

## 作成手順

「その他 → ツールバーを簡単作成…」または「編集 → ツールバーを簡単作成…」を開きます。

1. **形式を選ぶ**: 通常フォーム内のボタン列、またはMAIN専用の標準TOOLBARを選びます。
2. **ボタンを設定する**: 表示名・行う処理・幅を指定します。上から順に左→右へ並びます。
   選択行の処理本文やマクロパスを下で編集できます。「↑ 上へ」「↓ 下へ」で順序を変更します。
3. **確認して追加する**: ボタンの並びと生成PMLを確認します。「戻る」で設定を変更できます。

部品名・コールバック名は重複を避けて生成します。
長い表示名ではボタンの幅を広げ、既存部品と重ならない空きへ配置します。
横一列に収まらない場合は、幅・個数・フォームサイズを調整してください。
全体を1回のUndoで取り消せます。既存の16個・2行の部品パレットにボタンは増やしません。

## 形式の違い

| 形式 | 使う場所 | 作成する内容 |
| --- | --- | --- |
| 通常フォーム内のボタン列 | DIALOGフォームの中 | 通常FRAMEと、座標で横並びにしたBUTTON。既存のフォーム形式を保持します。 |
| 標準TOOLBAR | MAINフォーム | `FRAME .名前 TOOLBAR` とBUTTON。子部品のAT座標を省略し、宣言順に並びます。 |

通常フォーム内のボタン列は、フォーム内で使う操作ボタンのまとまりです。
E3Dのアプリケーションのリボンにボタンを登録する機能は含みません。

標準TOOLBARをDIALOGへ追加する場合は、画面でMAINへの変更を選びます。
配置済みの部品がMAINに対応しているか確認し、非対応の部品があれば変更せずに案内します。
MAINへ変更するとフォームのドッキングを解除します。
既存の出力仕様と同様、生成MACにはSHOWも出力します。MAINの表示・登録方法はE3D側のアプリケーションに合わせて調整してください。

公式資料では、標準TOOLBARはメニューバーのあるモジュール用で、タブ式のリボンメニューでは利用できません。
既存アプリケーションへの登録はE3D側で別途必要です。
この作成画面はフォームと操作メソッドを生成します。

## ボタンで行う処理

| 処理 | 内容 |
| --- | --- |
| 自分の処理 | PMLメソッドの本文を入力します。初期値は説明メッセージだけのサンプルです。 |
| 外部マクロ | 指定した `.mac` を既存のMACRO動作で呼び出します。ファイルは別途配置します。 |
| 現在要素の情報 | CEのNAME／TYPEをコマンド出力へ表示します。 |
| 直属の上位へ移動 | CEのOWNERへ1階層移動します。上位がない場合は案内して終了します。 |
| 直属の配下を表示 | CEのMEMBERSのNAME／TYPEをコマンド出力へ表示します。CEを移動しません。 |

「CEナビのサンプルを追加」で、`CE info`・`Up`・`Members` の3ボタンをまとめて追加できます。
表示名は日本語などに変更できます。現在要素が無効な場合は処理を止めるコードを生成します。
配下一覧は直属の子だけの文字出力で、ツリー表示ではありません。

例えばSITEを現在要素にして `Members` を押すと、そのSITE直属のZONEなどの名前・種類を表示します。
ZONEで `Up` を押すと、直属の上位のSITEへ移動します。

## 作成後の編集・保存

各ボタンを選び、「動作」で処理コードやマクロパスを編集できます。
設計JSONにはフレーム・ボタン・処理をまとめて保存します。
フレーム全体を複製／コピーすると子ボタンと処理を引き継ぎます。
標準TOOLBARの貼り付け先にはMAINフォームを使用してください。
生成MACの再読込でもボタンの処理を保持します。継続編集にはJSONを使用してください。
取り込み元の表示プログラムを保持する設計は、先に「取り込みコード」で表示プログラムを自動生成へ変更します。

[サンプル](../examples/toolbars/README.md)に通常ボタン列・標準TOOLBAR・外部マクロ付きのJSONとMACを同梱しています。
