# ツールバー・コンテナ・DBセレクタの入力確認

実際の作成画面を操作し、3種類を同じフォームへ追加して確認しました。
標準の用途は選択と基本項目の入力で設定でき、PMLやDLL名を手入力する必要はありません。
任意の処理・専用の.NET部品には、その処理や接続情報が必要です。

| 部品 | 基本の設定 | 確認結果 |
| --- | --- | --- |
| ツールバー | 形式、ボタンの表示名・処理・幅、並び順 | 3段階の案内で追加可能。CEナビの3ボタンはサンプルを選ぶだけで生成。 |
| コンテナの標準表 | 用途、表示名、大きさ、表のデータ元、単一／複数行選択 | 接続情報は入力済み。CEの配下をデータ元にすると列・行コードの入力も不要。 |
| DBセレクタ | 一覧の範囲、単一／複数選択、処理の種類と表示する情報 | 同じ作成画面で設定可能。日本語の選択肢を表示し、AUTOでは単一選択へ切り替える。 |

コンテナの接続先を変更する場合は「接続先・初期化の詳細を変更する」を開きます。
専用・自作の.NET部品では、DLL名・名前空間・コントロール型などを指定します。
ツールバーのカスタム処理はPMLの本文、外部マクロはファイルのパスが必要です。
DBセレクタの独自処理は1件処理の本文を入力します。

確認では、実際のメニューからDBセレクタ・標準表・CEナビのボタン列を追加し、8部品を配置しました。
JSONをファイルへ保存して再読込し、MACの再読込と4回のUndo／Redoでも設定と処理を保持しました。
キャンセル時に入力前のフォームを変更しないことも確認しています。
