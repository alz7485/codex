# DBセレクタのメソッドを簡単作成

既存のDBセレクタに、選択要素を処理するPMLメソッドを追加します。
FormDesigner内ではDB処理を実行せず、E3D用のコードを生成します。

## 操作

1. 「その他 → DBセレクタ」でセレクタを追加します。
2. 「動作」の「DBセレクタのメソッドを簡単作成…」を押します。
   「編集」または「その他」メニューからも開けます。
3. 対象、一覧の表示範囲、単一／複数の選択方法、処理の種類を同じ画面で設定します。
4. 右側の生成コードを確認します。
5. 「メソッドを追加」を押します。表示範囲・選択方式・メソッドをまとめて反映します。
   追加先に空きがない場合は、大きさを調整してください。

表示範囲は「現在要素の上位（OWNERS）」「現在要素の配下（MEMBERS）」
「CE変更に合わせて自動更新（AUTO）」から選びます。
AUTOでは単一選択に切り替え、複数選択を選べないようにします。
キャンセルした場合は、対象の設定も変更しません。

パレットは16個・8列×2行のままです。
メソッド、実行用ボタン、更新ボタンは1回のUndoで取り消せます。
通常のフレームやタブ内のセレクタには、同じ親の中へボタンを追加します。

## 処理の種類

| 種類 | 生成する処理 |
| --- | --- |
| 情報表示 | 選択要素のNAME、TYPE、直属のOWNERをコマンド出力へ表示。表示する項目を選べます。 |
| 現在要素へ移動 | 選択した1件を `!!CE` に設定。SINGLEと処理ボタンを使用します。 |
| My Data登録 | 選択した各要素をMy Dataへ追加。MyDataAddinアセンブリが必要です。 |
| 自分の処理 | 1件ごとに `!element`（DBREF）を渡して入力したPMLを実行。 |

標準の実行方法は「処理ボタンを追加して実行」です。
複数の対象を選び終えてからボタンを押せます。既存のセレクタの選択時処理は保持します。

情報表示と自分の処理では「選択が変わったときに実行」も選べます。
この方式では、選び直すたびにその時点の選択全体を処理します。
既存の選択時処理がある場合は、置き換えのチェックが必要です。生成コードはチェック前にも確認できます。
共有している別の部品の処理は変更せず、以前の処理が明示的に呼び出される場合もメソッドを保持します。

## 生成メソッドの構成

例えばメソッド名が `processSelector1` の場合:

| メソッド | 役割 |
| --- | --- |
| `processSelector1()` | 選択行を記録し、各DBREFを1件処理へ渡します。 |
| `processSelector1Element(!element is DBREF)` | 1件ごとの属性表示・登録・カスタム処理を行います。 |
| 処理ボタンのクリックメソッド | `processSelector1()` を呼びます。 |
| 更新ボタンのクリックメソッド | 対象のセレクタの `Refresh()` を呼びます。 |

`DO SELECTOR` は選択された表示文字列を取り出します。`.val` をDBREFとして扱いません。
処理開始前に選択全体を配列へ記録するので、CEの変更でセレクタが更新されても、実行対象の取得は終わっています。
単一選択・複数選択には共通のループを使い、対象が0件の場合は案内を出して終了します。
最後に表示する件数は、1件処理を呼び出した件数です。

## 自分の処理の例

「1件ずつ自分の処理を実行」で、次のような本文を入力できます。

```pml
!owner = !element.owner
q var !owner
```

各選択要素の直属の上位を確認します。`DEFINE METHOD` と `ENDMETHOD` は不要です。
作成後は「編集 → 補助メソッド管理」で、`processSelector1Element` の本文を編集できます。
処理ボタンのメソッドは、部品の「処理コードを編集」から変更できます。

## 保存・再利用

設計JSONにボタンと補助メソッドを保存します。
セレクタの名前変更では、処理メソッドと更新ボタンの参照も変更します。
処理ボタン方式のセットを再利用するときは、セレクタとボタンを入れたフレーム／タブをまとめてコピーしてください。
選択時実行方式なら、セレクタ単体のコピーでも関連する補助メソッドを引き継ぎます。
生成MACの再読込でもメソッドを保持します。継続編集には設計JSONを使用してください。
取り込み元の表示プログラムを保持する設計では、先に「取り込みコード」で表示プログラムを自動生成へ変更してください。

## E3Dでの確認

E3D 4.0向けの作成支援です。コード生成・保存・コピーを検証し、E3D実機での実行は未確認です。
表示範囲は対象の設定を初期値とし、作成画面内で変更できます。AUTOとMULTIPLEは公式仕様上併用できません。
更新ボタンはその時点のCEを基準に一覧を更新します。
名前・種類の表示ではDB属性を変更しません。カスタム処理の実際の動作は入力したPMLによります。
