# .NET部品の簡単作成（E3D 4.0向け）

「その他 → .NET部品を簡単作成…」または「編集 → .NET部品を簡単作成…」を開きます。
種類を選んで設定を入力し、右側のPML例を確認して「フォームへ追加」を押します。
選択中の通常フレーム、表示中のタブ、またはフォームの空き領域に配置します。
上部のボタン群は16個・2行のままです。追加とコード生成は1回のUndoで戻せます。

表の標準接続情報は入力済みです。最初は用途・表示名・大きさ・データ元だけ設定できます。
DLLや初期化処理を変更する場合は「接続先・初期化の詳細を変更する」を開きます。
詳細を閉じても入力した設定は保持します。
専用・自作部品では必要な接続欄を常に表示します。

## 作成できるもの

| 種類 | 設定から作る内容 | E3D側で必要なもの |
| --- | --- | --- |
| 表 | CONTAINER、NetGridControl、列・行配列、データ接続、読み取り専用設定、単一／複数行選択 | GridControlアセンブリとPML.NET公開API |
| ファイルを開く／保存 | ボタン、PMLFileBrowser、フィルター、初期フォルダー、取得したパスの処理メソッド | PMLFileBrowserアセンブリ |
| My Data登録 | 現在要素の確認と、My Dataへ登録するボタン・処理メソッド | MyDataAddinアセンブリ |
| Flexible Explorer接続 | 指定されたPML.NET部品の宣言・生成・コンテナ接続 | PML.NET対応ラッパーDLLと表示定義・初期化処理 |
| サポート寸法部品 | 専用コントロールの宣言・生成・コンテナ接続 | 対応DLL、寸法設定、表示対象に合わせた初期化処理 |
| 自作／外部部品 | DLL、名前空間、型から宣言・生成・接続 | PML.NET対応のコントロールDLL |

## 表の例

1. 「表（Grid Control）」を選びます。
2. 「手入力した行データ」なら列見出しを1行1列で入力します。
3. 行データはTab区切りです。Excelから表をコピーして貼り付けることもできます。
   見出しだけの表は、行データを空欄にして作ります。
4. 「現在要素の直属の配下」なら、フォーム生成時のCEのMEMBERSからName／Typeの2列を作ります。
   SITEをCEにすれば、通常は直属のZONEが対象になります。再帰検索や種類による絞り込みは行いません。
5. 必要なら「行の選択を1行に限定する」をオンにします。
6. 部品名・大きさを設定して追加します。

表は読み取り専用で、DBへの書き戻し処理は生成しません。
CE配下の表はフォーム生成時に取得する一覧です。CE変更に伴う自動更新は行いません。
作成後の初期化処理は、部品プロパティの「NET初期化コードを編集…」から変更できます。
部品名の変更・複製・別設計へのコピーでは、初期化コード内のコントロール参照も追従します。
設計JSONには初期化コードも保存します。

## ファイル選択とMy Data

ファイル選択はダイアログを表示してパスを取得します。「保存」を選んでもファイル自体の書き込みは行いません。
生成したクリックメソッドの `!selectedFile` を使う部分に、読込・書込の処理を追加してください。
キャンセルで空のパスが返ったときは、処理を終了します。
My Data登録ボタンはクリック時のCEを1件登録します。DB要素の属性は変更しません。

## 専用・自作部品

Flexible Explorerの公式例はC#アドインです。アドインDLLをそのままPML.NETコンテナへ接続できるとは限りません。
この選択肢はPML.NET対応ラッパーを既に持つ利用者向けの接続ひな型です。
DLL名・名前空間・公開コントロール型を入力してください。XML表示定義や選択イベントの接続は、その部品のAPIに合わせて追加します。
サポート寸法部品も、接続だけでは表示対象を設定できません。対応する寸法設定と初期化が必要です。
ウィザードはDLLの作成・コンパイル・配置を行いません。

## E3D 4.0での確認

公開された2.1／3.1の公式資料の構成を基にしています。4.0の実機・参照DLLによる確認は未実施です。
表の初期名前空間は `Aveva.Core.Presentation` です。DLL名・名前空間・型は変更できます。
既存の4.0環境の動作するPMLや、インストールされたSamplesを優先して照合してください。
コンテナのプレビューは配置確認用の代替表示です。.NET画面部品そのものはE3D上で表示します。
IMPORTでは公式例の既読込エラー `(1000,0)` のみを処理し、それ以外の読込エラーは隠しません。

元コンストラクタまたは表示プログラムを保持する取り込み設計では、コードが無視されないよう新規追加を止めます。
「取り込みコード」で該当項目を自動生成へ切り替えるか、元コードを編集してください。
生成MACを再読込すると表の初期化は元コンストラクタとして保持されます。継続編集には設計JSONを使用してください。
