# 詳細マニュアルの読み方

FormDesigner上部の操作列の右端の❔、またはF1で同梱のブラウザー版を開けます。

- [ブラウザー版](index.html): 目次・目次検索・Ctrl+F・印刷を使用できます。
- [PDF版](FormDesigner-Manual.pdf): PDFビューアーで開くか印刷します。
- [Markdownの原本](../../MANUAL.md): Markdown対応エディターなどで読めます。

HTMLが見つからない場合はPDFを開きます。
HTML内の画像は埋め込まれているので、マニュアル閲覧にネット接続は不要です。
サンプルへのリンクを使う場合は、ZIPのフォルダー構成を保持してください。
