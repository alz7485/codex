# 改善候補

## 実装済み（2026-10-07）

- 別名保存、保存先・MAC出力先の表示。
- 設計ファイルを基準にした相対パスの画像プレビュー。
- 背景透過のアプリアイコンと、アイコン付きonedirビルドスクリプト。
- 作業手順に沿った画面切り替え、全ボタンの常時表示、部品名・処理名の自動設定、TABSETのまとめて追加。
- 最近の設計10件、出力先設定と共存する履歴の保存。
- 未保存作業の30秒ごとのバックアップ、起動時・手動の復元、セッション間のロック。

## 次に優先する候補

1. **配置の補助**：グリッドへのスナップを切り替え、左・中央・右の整列や等間隔配置を行う。既存の複数選択を拡張する際は、従来修正した「選択していない部品が一緒に動く」問題を再発させないよう、明示的な操作へ限定する。
2. **部品の再利用**：よく使う入力欄・ボタン・フレームの組を部品セットとして登録し、名前やコード参照を衝突させず追加する。
3. **検証の案内**：コード欄のエラーから対象部品と設定項目を選べるようにし、何を修正すればよいかを示す。
4. **共有する設計一式の出力**：JSON・MAC・画像をまとめたZIPの作成。画像パスの相対化と、E3D側での配置先を指定する必要がある。
5. **E3D実機での互換確認**：TABSET、RTOGGLE、TOOLBAR、VIEW、CONTAINER等の実行例を集め、プレビューと実際の差を調整する。

上記の候補は未実装です。既存MACの厳密／部分取り込み、共通メソッド管理、複数選択、F6参考表示は実装済みです。動的な参照や未対応のE3D固有構文は取り込み後に手動確認が必要です。

追加候補：修正箇所へ移動できる診断一覧、リネーム・MAC出力前の差分表示、文字入力をまとめたUndo、複数選択のまとめてコピー、Windows CIでのonedir起動確認。
