# 改善候補

## 実装済み（2026-10-05）

- 別名保存、保存先・MAC出力先の表示。
- 設計ファイルを基準にした相対パスの画像プレビュー。
- 背景透過のアプリアイコンと、アイコン付きonedirビルドスクリプト。
- 最近の設計10件、出力先設定と共存する履歴の保存。
- 未保存作業の30秒ごとのバックアップ、起動時・手動の復元、セッション間のロック。

## 次に優先する候補

1. **配置の補助**：グリッドへのスナップを切り替え、左・中央・右の整列や等間隔配置を行う。複数選択を導入する際は、従来修正した「選択していない部品が一緒に動く」問題を再発させないよう、明示的な操作へ限定する。
2. **部品の再利用**：よく使う入力欄・ボタン・フレームの組を部品セットとして登録し、名前やコード参照を衝突させず追加する。
3. **検証の案内**：コード欄のエラーから対象部品と設定項目を選べるようにし、何を修正すればよいかを示す。
4. **共有する設計一式の出力**：JSON・MAC・画像をまとめたZIPの作成。画像パスの相対化と、E3D側での配置先を指定する必要がある。
5. **E3D実機での互換確認**：TABSET、RTOGGLE、TOOLBAR、VIEW、CONTAINER等の実行例を集め、プレビューと実際の差を調整する。

上記の候補は未実装です。既存MACの取り込みは、手書きの処理・外部参照・E3D固有構文を保持する設計が必要なため、別の機能として検討します。
